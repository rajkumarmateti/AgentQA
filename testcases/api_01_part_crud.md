# API: Part CRUD — `/api/part/` and `/api/part/{id}/`

**Schema:** GET/POST/PATCH/PUT `/api/part/` · GET/PATCH/PUT/DELETE `/api/part/{id}/`  
**Success codes:** GET/PATCH/PUT **200** · POST **201** · DELETE **204**

Setup: authenticated USER-OK. Cleanup: DELETE created parts unless the case is the delete itself.
