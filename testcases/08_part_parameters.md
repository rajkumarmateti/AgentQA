# Feature: Part Parameters

**Docs:** [Parameters](https://docs.inventree.org/en/stable/concepts/parameters/) · [Part Views — Parameters](https://docs.inventree.org/en/stable/part/views/#parameters) · [Enforce Parameter Units](https://docs.inventree.org/en/stable/settings/global/#parameter-templates)

Parameters are metadata (not core business logic). Templates are managed in Admin Center. Locked parts cannot have parameters created, edited, or deleted.
