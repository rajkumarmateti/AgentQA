# Feature: Part Creation (Manual)

**Docs:** [Creating Parts](https://docs.inventree.org/en/stable/part/create/) · [Parts](https://docs.inventree.org/en/stable/part/) · [Global settings — Parts](https://docs.inventree.org/en/stable/settings/global/#parts)

New parts are created from the Parts view via **Add Parts → Create Part**. On success the browser is redirected to the new part detail page. Form errors must be fixed before submit. **Add Parts** is hidden if the user lacks Part **create** permission.
