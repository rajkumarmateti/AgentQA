# Feature: Part Revisions

**Docs:** [Revisions](https://docs.inventree.org/en/stable/part/revision/) · [Settings](https://docs.inventree.org/en/stable/settings/global/#parts)

A revision is itself a part, linked via **Revision Of**. Create a revision with **Duplicate Part**, then set Revision Of and a unique Revision code. Related data on the original part is not rewritten.
