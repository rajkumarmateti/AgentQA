# Feature: Part Import

**Docs:** [Creating Parts — Import](https://docs.inventree.org/en/stable/part/create/#import-from-file) · [Data Import](https://docs.inventree.org/en/stable/concepts/data_import/) · [Part Import](https://docs.inventree.org/en/stable/part/#part-import)

Parts can be imported from a file via **Add Parts → Import from File**, which opens the data import wizard. Import from a supplier requires a supplier mixin plugin. Admin Center import requires a **staff** user with **change** permission. Multi-level import is not supported. Mixing create and update in one session is not supported.
