# Feature: Part Categories

**Docs:** [Part Category](https://docs.inventree.org/en/stable/part/#part-category) · [Parametric tables](https://docs.inventree.org/en/stable/concepts/parameters/#parametric-tables) · [Category parameter templates](https://docs.inventree.org/en/stable/settings/global/#categories)

Categories are hierarchical. A category list shows parts in that category **and** in sub-categories, plus the list of sub-categories. Lists can be filtered. Parametric view supports parameter sort/filter.
