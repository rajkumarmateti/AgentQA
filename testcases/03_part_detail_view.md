# Feature: Part Detail View

**Docs:** [Part Views](https://docs.inventree.org/en/stable/part/views/) · [Parts](https://docs.inventree.org/en/stable/part/)

The part detail page shows category breadcrumbs, a toggleable details header, and tabs whose visibility depends on part attributes and feature flags.

| ID | Area | Scenario | Preconditions | Test Data | Steps | Expected Result | Type | Priority |
