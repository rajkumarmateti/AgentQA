# Feature: Cross-Functional Behavior

**Docs:** Combined behavior from [Parts](https://docs.inventree.org/en/stable/part/), [Creating Parts](https://docs.inventree.org/en/stable/part/create/), [Part Views](https://docs.inventree.org/en/stable/part/views/), [Parameters](https://docs.inventree.org/en/stable/concepts/parameters/), [Revisions](https://docs.inventree.org/en/stable/part/revision/), [Virtual](https://docs.inventree.org/en/stable/part/virtual/), [Consumable](https://docs.inventree.org/en/stable/part/consumable/), [Templates](https://docs.inventree.org/en/stable/part/template/), [BOM](https://docs.inventree.org/en/stable/manufacturing/bom/).

Each case starts in one Parts capability and asserts a visible effect in another.
